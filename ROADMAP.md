# Roadmap

Themes, not tickets. Dates intentionally flexible.

## Near term

- Server-assisted offline skin compatibility guidance
- Stronger first-run confidence for non-technical players
- Accessibility passes across Skin Studio and dense settings
- Expanded diagnostics that stay human-readable

## Mid term

- Richer library workflows (worlds / packs / backups mindset)
- More resilient update & trust storytelling for Windows users
- Accessibility passes on primary flows

## Long term

- Broader ecosystem surfaces without sacrificing profile safety
- Optional advanced power-user modes that don’t pollute the default UI

## Non-goals (for now)

- Becoming a generic “everything launcher” clone
- Publishing proprietary internals for the sake of open-source optics
