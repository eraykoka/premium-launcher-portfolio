# Development Process

## Product loop

1. Identify user friction
2. Decide with explicit tradeoffs
3. Ship the smallest correct improvement
4. Document outcomes for the team brain
5. Release through the product channel

## Engineering judgment

Prefer:

- Extending working modules over fashion rewrites
- User-visible reliability over clever abstractions
- Protecting IP while still communicating competence publicly

## What this portfolio proves

- Ability to own a full desktop product surface
- UI systems thinking
- Release discipline
- Security-minded distribution awareness
- Documentation as a professional artifact
