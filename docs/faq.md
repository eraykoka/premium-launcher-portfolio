# FAQ

### Is this open source?
No. This repository is a **portfolio showcase**.

### Why not publish the code?
Because the competitive value is the product itself—architecture choices, UX, health workflows, and distribution trust. Publishing those internals would enable clones without the years of iteration.

### What can interviewers ask?
Outcomes, tradeoffs, UX rationale, risk management, Windows desktop constraints, release strategy—at a conceptual level.

### Where are screenshots / videos?
See [`gallery.md`](gallery.md), [`../images/`](../images/), and [`../videos/`](../videos/).

### Can companies request a private walkthrough?
Yes—contact via GitHub. Private demos can be arranged without handing over source.
