# Design Philosophy

## Commercial desktop product, not a skin

Premium Launcher is designed to feel like shipping software:

- Clear hierarchy
- Predictable navigation
- Restrained color (action crimson, ambient purple, success green)
- Motion used for feedback—not decoration storms

## List-first information design

Dense tools (especially Mods) prioritize the working list. Status summaries stay slim unless the user expands them—similar to modern Git clients and professional launchers.

## Trust UI

Trust is a UI problem as much as a systems problem:

- Avoid scary walls of technical noise
- Prefer status + action
- Keep destructive actions explicit

## Consistency over novelty

A small design system beats one-off screens. Tokens drive spacing, type, and surfaces so new features inherit the brand automatically.
