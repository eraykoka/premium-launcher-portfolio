# Security Policy

## Supported surfaces

Security reports should concern the **shipped Premium Launcher product** and its official distribution channels—not hypothetical reconstructions from this portfolio repo.

## Reporting

Please contact the maintainer privately via GitHub security advisories (if enabled) or a private message to [@erayakbayy](https://github.com/erayakbayy).

Include:

- Impact summary
- Affected version (if known)
- Reproduction at a high level

Do **not** attach proprietary dumps, user tokens, or full exploit chains in public issues.

## Disclosure

Coordinated disclosure preferred. Critical issues affecting end users will be prioritized.
